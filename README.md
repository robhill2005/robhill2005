## Silver Hill Data Platform

The unifying work is a reusable architecture and engineering method — the **Silver Hill Data Platform**. The individual projects below are domain proof points: materially different systems that exercise and validate the same principles.

Two pipelines run through the work:

```
Evidence → Normalize → Model → Govern → Declare Capability
→ Ask → Explain → Act
```

```
Design → Build → Test → Independent Review
→ Human Gate → Merge → Document → Repeat
```

The approach emphasizes strong data foundations, explicit provenance, semantic contracts where appropriate, deterministic calculations where correctness matters, bounded AI, and human gates around consequential actions.

> **Governed AI is leverage, not authority.** Use AI to discover, interpret, draft, explain and accelerate — not to silently replace source evidence, deterministic computation, provenance or human judgment.

A related product principle is simple: **solve a concrete problem first; generalize from evidence, not imagination.**

## Projects

### SHARE — Silver Hill Asset Return Engine

Institutional asset-management data platform and the deepest reference implementation today. Single-user Silver Hill relationship, campaign and opportunity workspace. The first real campaign is the Virginia scouting/business-development trip — Richmond, Staunton and Roanoke — with the broader product intended to preserve durable relationships across campaigns and geography. ### RUDL — Richmond Urban Data Lab

A reproducible analytics platform built from Richmond, Virginia public data. Nine official sources feed immutable Bronze evidence, Silver contracts and Gold analytical products through DuckDB/DuckLake, with source hashes, execution lineage and an eight-page Streamlit portal. Its optional AI briefing follows a **compute first, explain second** pattern: deterministic answers work without an LLM; AI may explain the governed result.

### SHIP — Silver Hill Investment Platform

Market and trading experimentation: portfolio/research workflows, market data, AI-assisted trade scoring, journaling, daily signal snapshots and backtesting. SHIP is deliberately an experimentation sandbox rather than a claim that the full Silver Hill governance model has already been adopted there.

### NextPath

An AI-assisted planning and workflow product — **Think → Plan → Build → Track Results** — turning goals into editable plans, actions, routines and resources. The repository originated as `mindmap-ai`; AI-generated resource ideas are explicitly presented as illustrative/unverified.

## Common pattern

- preserve source evidence before interpretation when source evidence exists
- state facts, dimensions, events and grain explicitly
- separate actual / derived / synthetic
- preserve lineage and temporal semantics
- deterministic computation before generative explanation
- governed semantic/capability boundaries where appropriate
- unavailable / deferred / ambiguous are valid states
- read / query authority separate from consequential action / writeback
- solve real workflows first and generalize only after evidence
- small, independently reviewed increments with a human merge gate
